# Project planning

Use GitHub issues in `LaskasP/the-art-of-healing` as the canonical issue tracker, using the `gh` CLI.

The wayfinder map is [Plan the psychologist website](https://github.com/LaskasP/the-art-of-healing/issues/1). Decision tickets are native sub-issues; blocking uses native issue dependencies. Read the map before continuing planning and consult relevant child issues and comments as needed.

Record decisions and progress on GitHub; do not maintain duplicate local issue files.
